 AUTO SYSTEMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Proxy Auto-Fetch:
    - Runs every 2 minutes (PROXY_REFRESH_INTERVAL=120)
    - Fetches from Urban VPN using PROXY/fetcher.py
    - Replaces proxies.txt atomically
    - Prints total fetched to console
    - Does NOT interrupt running checks (each CheckerSession
      has its own ProxyRotator snapshot taken at start)

  DB Auto-Backup:
    - Sends initial backup 5s after bot start
    - Then every 24h (BACKUP_INTERVAL=86400)
    - Sends ZIP with bot_database.json + proxies.txt to ADMIN_ID
